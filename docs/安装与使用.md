# 安装与使用

规则辅助，不构成收益承诺。不下单，也不使用内幕消息。

支持 **Windows** 与 **macOS** 本机使用。两边都只监听 `127.0.0.1`，数据落在各自用户目录。

---

## 1. Windows 用户：安装包

### 1.1 系统要求

- Windows 10 / 11（64 位）
- 可访问行情相关公网
- **建议**本机已安装通达信（读取 `connect.cfg` 主站）；未安装也可启动，部分能力可能降级

无需自备 Python。

### 1.2 安装

1. 双击 `买入时机-Setup-x.y.z.exe`
2. 按向导下一步
3. 开始菜单打开「买入时机」

便携包：解压 `买入时机-portable-x.y.z.zip` 后双击 `Start.bat`。

### 1.3 日常使用

- 关闭启动器控制台或 `Ctrl+C` 即停服务
- 数据：`%LOCALAPPDATA%\买入时机\market.db`
- 浏览器：http://127.0.0.1:8765

### 1.4 卸载

「应用和功能」中卸载。默认**保留** `%LOCALAPPDATA%\买入时机\`。

---

## 2. macOS 用户：.app / DMG / 便携包

### 2.1 系统要求

- macOS 11+（Apple Silicon 或 Intel，需与构建包架构一致）
- 可访问行情相关公网
- **通达信为 Windows 客户端**：Mac 上一般检测不到，将自动走备用行情主站（功能可用，稳定性/覆盖可能弱于 Windows+通达信）

无需自备 Python（使用打好的便携 runtime）。

### 2.2 安装

任选其一（向维护者索取对应产物）：

| 产物 | 用法 |
| --- | --- |
| `买入时机-mac-*-.dmg` | 打开 DMG，拖 `买入时机.app` 到「应用程序」或任意目录 |
| `买入时机.app` | 直接双击（可放「应用程序」） |
| `买入时机-mac-portable-*.zip` | 解压后双击 `Start.command` |

若提示「无法打开 / 已损坏」：

```text
xattr -cr "/Applications/买入时机.app"
```

或对 app / 解压目录右键 → 打开。

### 2.3 日常使用

- 双击 `.app` 会打开「终端」跑启动器；关闭该终端窗口即停服务
- 便携包：双击 `Start.command`（若无权限：`chmod +x Start.command`）
- 数据：`~/Library/Application Support/买入时机/market.db`
- 浏览器：http://127.0.0.1:8765

### 2.4 卸载

删除 `买入时机.app`（及 DMG/解压目录）。  
数据默认保留在 `~/Library/Application Support/买入时机/`，不需要时可手动删。

## 3. 常见问题（两边通用）

| 现象 | 处理 |
| --- | --- |
| 端口被占用 | 结束占用 `8765` 的进程后再启动 |
| Mac 无通达信 | 预期行为；用备用主站。若有拷贝的 `connect.cfg` 目录，可设环境变量 `TDX_HOME` |
| 首次池子很慢 | 后台在补日 K，看页面覆盖进度 |
| 浏览器没弹出 | 手动打开 http://127.0.0.1:8765 |
| Windows 杀软拦截 | 安装目录加入信任 |

## 4. 维护者：打出安装包

### 4.1 Windows 构建（在 Windows 上）

前置：Inno Setup 6、可访问 python.org / PyPI。

```text
powershell -ExecutionPolicy Bypass -File scripts\build-installer.ps1
```

产物：`dist\买入时机-Setup-*.exe`、`dist\买入时机-portable-*.zip`。

### 4.2 macOS 构建（须在 Mac 上执行）

前置：Xcode CLT（含 `curl`/`hdiutil`）、可访问 GitHub Releases 与 PyPI。

```text
chmod +x scripts/build-installer-mac.sh packaging/Start.command packaging/macos/AppExec.sh
./scripts/build-installer-mac.sh
./scripts/build-installer-mac.sh --version 0.1.1
```

产物：

| 文件 | 说明 |
| --- | --- |
| `dist/买入时机-mac-portable-*-arm64.zip` 或 `x86_64` | 便携目录 |
| `dist/买入时机.app` | 双击启动 |
| `dist/买入时机-mac-*-.dmg` | 分发用磁盘映像 |

脚本会下载 [python-build-standalone](https://github.com/astral-sh/python-build-standalone) 的 macOS 独立 Python，再装 [`requirements-runtime.txt`](../requirements-runtime.txt)。

若下载 404：到该仓库 Releases 查看最新日期标签，例如：

```text
./scripts/build-installer-mac.sh --date 20250317 --py 3.12.8
```

**注意**：请在与用户相同的架构上构建（M 系列用 arm64，Intel 用 x86_64），或分别打两个包。

### 4.3 环境变量

| 变量 | 含义 | 默认 |
| --- | --- | --- |
| `STOCKDECISION_HOST` / `HOST` | 监听地址 | `127.0.0.1` |
| `STOCKDECISION_PORT` / `PORT` | 端口 | `8765` |
| `STOCKDECISION_DB_PATH` / `DB_PATH` | SQLite | 启动器：系统用户数据目录 |
| `STOCKDECISION_TDX_HOME` / `TDX_HOME` | 通达信目录 | Windows 探测；Mac 通常不设 |

请保持 `HOST=127.0.0.1`，勿对公网裸暴露。

## 5. 开发者：源码直接跑

Windows / macOS 相同：

```text
python3 -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python -m app
```

或：`python scripts/launcher.py`（推荐，数据进用户目录）。

## 6. Windows：开盘自动运行

用任务计划程序在工作日自动启停本机助手（**不含法定假日日历**：节假日落在周一至周五仍可能启动）。

| 任务 | 时间 | 动作 |
| --- | --- | --- |
| `StockDecision-Start` | 周一至周五 09:10 | 启动 launcher / Start.bat；若当时关机，开机后会尽量补跑（StartWhenAvailable） |
| `StockDecision-StartOnLogon` | 每次登录 | 若仍是工作日且在 09:10–15:10 内、8765 未占用，则补启（解决「九点多才开机」） |
| `StockDecision-Stop` | 周一至周五 15:10 | 结束占用 8765 端口的进程 |

午间休市不停服务。例如 10:00 才开机并登录，会由 `StartOnLogon` 自动拉起；15:10 仍会停。注册（当前用户，需已登录）：

```text
powershell -ExecutionPolicy Bypass -File scripts\schedule-market-hours.ps1 -Action Register
powershell -ExecutionPolicy Bypass -File scripts\schedule-market-hours.ps1 -Action Status
```

卸载：

```text
powershell -ExecutionPolicy Bypass -File scripts\schedule-market-hours.ps1 -Action Unregister
```

可在「任务计划程序」中手动右键运行 `StockDecision-Start` 做验收。停止脚本也可单独用：`scripts\stop-server.ps1`。
